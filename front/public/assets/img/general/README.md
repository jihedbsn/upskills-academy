# Logo SAST - Swedish Academy of Sport Training

## Instructions pour ajouter le logo

1. **Créez votre logo PNG** avec les spécifications suivantes :
   - Texte principal : "SAST"
   - Sous-titre : "Swedish Academy of Sport Training"
   - Format : PNG avec fond transparent
   - Taille recommandée : 200x80px
   - Couleurs suggérées : 
     - Texte principal : #6440FB (violet)
     - Sous-titre : #242239 (gris foncé)

2. **Nommez le fichier** : `logo-sast.png`

3. **Placez-le dans ce dossier** : `public/assets/img/general/`

4. **Outils recommandés** pour créer le logo :
   - Canva (gratuit en ligne)
   - Figma (gratuit)
   - Adobe Illustrator
   - GIMP (gratuit)

## Structure du logo

Le logo doit être simple et professionnel, avec :
- L'acronyme "SAST" en grand
- Le nom complet en plus petit en dessous
- Un design moderne et épuré
- Compatible avec le thème violet du site

## Utilisation

Le logo sera automatiquement utilisé dans :
- Le header du site
- Le footer
- Le dashboard admin
- Toutes les pages du site
